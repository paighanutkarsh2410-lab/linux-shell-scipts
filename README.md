# Linux Shell Scripts

This repository contains Bash scripts created while learning Linux system administration and automation.

The scripts cover common Linux administration tasks such as system monitoring, backup automation, user management, disk monitoring, service management, networking, and package management.

---

## Scripts Included

- System Health Monitoring
- Directory Backup Automation
- User Creation and Deletion
- Disk Usage Monitoring
- Large File Finder
- Service Monitoring
- Log Cleanup Automation
- Network Connectivity Check
- Package Installation Automation
- System Information Report

---

## Technologies Used

- Linux
- Bash Shell Scripting
- Systemd
- Cron
- Linux Command Line Tools

## Usage

Give execution permission:

```bash
chmod +x script_name.sh
```

Run the script:

```bash
./script_name.sh
```
